# Stocks, Bonds & Cash Over the Long Run

Interactive chart: growth of a single $10,000 invested in U.S. stocks (S&P 500 price index),
bonds (Ibbotson U.S. govt 1958–75 spliced into the Bloomberg U.S. Aggregate 1976+) and
cash (30-day Treasury bills) from 1957 to 2026, on a ratio (log) scale.

- Adjustable time frame (Max / 40Y / 25Y / 15Y / 10Y / 5Y) with an auto-rescaling y-axis
- Y-axis toggle: dollar value or cumulative % return
- "From" toggle: grow from 1957, or rebase every line to the start of the visible window
- Level-of-detail event annotations — more market events appear the further you zoom in
- Hover / tap for values on any date

Single self-contained `index.html` (only external dependency: Google Fonts).
Figures are illustrative; annual-return inputs are approximate. Not investment advice.
